# รายงานศักยภาพการใช้จ่ายงบประมาณ พ.ศ. 2569

เว็บแสดงรายงานรายหน่วยงาน ข้อมูลมาจาก Excel 2 ไฟล์ในโฟลเดอร์ `data/`

- `data/budget.xlsx` ชีท "ใช้งาน"
- `data/KPI_summary.xlsx` ชีท "สรุปรายหน่วยงาน" และ "รายตัวชี้วัด"

ทุกครั้งที่อัปโหลดไฟล์ใหม่ GitHub Actions จะสร้าง `data.json` และเผยแพร่เว็บให้อัตโนมัติ (1-2 นาที)
รหัสผ่านเข้าเว็บ: ตั้งใน `web/index.html` ที่ `CONFIG.PASSWORD` (ตรวจฝั่งหน้าเว็บ ไม่ใช่การป้องกันข้อมูลจริง)
